Everything a power user wants, nothing that slows you down

Local-first, no telemetry, bring your own AI key. A background daemon does the heavy lifting so typing never stutters.

→_

Ghost-text autocomplete

Start typing git, docker, kubectl — or any private in-house CLI — and accept the full suggestion with Tab or →.

⌘

Plain English → command

Press CtrlSpace, describe the task, and get a modal with the command, an explanation, and a safety verdict.

⚠

Destructive-command gate

rm -rf, force-pushes, DROP TABLE: the first Enter only arms the dialog — y executes, e sends it back to your prompt.

⟳

Universal & dynamic parsing

No hand-written specs. chelp crawls --help and man pages on demand, tracks binary mtimes, and re-indexes when tools update.

⚿

Bring your own key

Gemini, OpenAI, Anthropic, Ollama (fully offline), or any OpenAI-compatible endpoint. Keys live in ~/.chelp/config.toml — never on a server.

▣

Shell & terminal agnostic

Zsh, Bash ≥ 4, Fish, PowerShell — inside iTerm2, Ghostty, Windows Terminal, you name it. Diagnostics go to a rotating log, never your prompt.

zsh · ZLE widgets bash ≥ 4 · bind -x fish · commandline powershell · PSReadLine macOS · Linux · Windows

Two triggers, one safe workflow

Deterministic autocomplete for what you know; AI for what you don't — with a human decision point before anything executes.

Type — or just ask

Enterprise-grade privacy & transparent economics

Built for air-gapped environments, strict security reviews, and engineering teams that want AI power without paying $19/dev/mo seat taxes.

🛡️

Zero telemetry guarantee

0 outbound tracking, 0 telemetry calls, 0 pings. In Ollama mode, packets never leave your machine (supports Unix sockets). Verify with chelp privacy.

🔐

Credential vault friendly

Avoid plaintext configs in dotfiles. Inject keys via CHELP_API_KEY from 1Password or Bitwarden CLI. Seamless CI/CD and workstation deployment.

💰

$1.50/dev/month vs $19 Copilot

BYOK with Gemini 2.5 Flash averages under $2/month for high-volume terminal power users. 10x cost reduction across your engineering organization.

📁

Schema-only caching (GDPR)

SQLite caches parsed --help flags only — NEVER your typed commands or terminal history. Purge anytime with chelp cache clear.

⚡

AST & heuristic guardrails

Hard gates on destructive operations: terraform destroy, kubectl delete ns, docker prune, rm -rf, force pushes.

🪟

PowerShell & Windows native

Native cmdlets, configurable backslash formatting (path_style = "windows"), and out-of-the-box PSReadLine keybinding integration.

Installation

Pick your platform. After installing, run chelp setup to wire the shell hook and choose an AI provider — full walkthrough in the quickstart.

Homebrew macOS / Linux

Formula from the official tap.

$ brew install 1Yosh1/tap/chelp

Install script macOS / Linux

One-liner; installs the latest release binary.

$ curl -fsSL https://raw.githubusercontent.com/1Yosh1/commandhelp/master/install.sh | bash

Cargo from source

Build straight from the repository with the Rust toolchain.

$ cargo install --git https://github.com/1Yosh1/commandhelp.git

PowerShell Windows

Run in PowerShell to install for the current user.

> irm https://raw.githubusercontent.com/1Yosh1/commandhelp/master/install.ps1 | iex
After install: run chelp setup — it detects your shell, appends the hook to your profile, and lets you pick Gemini / OpenAI / Anthropic / Ollama / any OpenAI-compatible endpoint.
