⚡

Zero-Latency Autocomplete (<1ms)

Uses an in-memory Trie and SQLite schema cache over local IPC (Named Pipes on Windows, Unix sockets on macOS/Linux). It never stalls your prompt.

📖

Universal Dynamic Parser

Parses --help on the fly across GNU, Cobra, and POSIX styles. Automatically indexes niche internal company scripts without pre-written JSON schemas.

🛡️

Interactive Blast-Radius Guardrails

High-risk commands (rm -rf, DROP TABLE, force pushes) require explicit multi-key confirmation before executing.

🔑

Client-Side DLP Secret Redaction

Local regex and entropy scanners scrub AWS keys, GitHub PATs, JWTs, and passwords from prompts before sending anything to remote LLMs.

🤖

100% Free BYOK & Offline Ollama

Zero API markup. Use Gemini Flash (free tier), Claude 3.5, GPT-4o, or run completely offline with local Ollama.

💻

Universal Shell Agnostic

Works smoothly inside PowerShell, Zsh, and Bash across Windows Terminal, iTerm2, Alacritty, Ghostty, and Kitty.

🔒 Zero Keystroke Logging. 100% Local-First.

Unlike cloud-reliant terminals, chelp does not stream your terminal session to remote servers. All `--help` crawler probing and documentation parsing occur entirely on your local CPU.
